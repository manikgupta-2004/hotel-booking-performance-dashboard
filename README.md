# Hotel Booking Performance Dashboard

An interactive business analytics dashboard built to analyze hotel booking performance, revenue, commission costs, OTA contribution, city-wise performance and hotel-level trends.

## Project Overview

This project analyzes hotel booking data and presents key business metrics through an interactive dashboard built using Google Sheets and Looker Studio.

The dashboard provides a consolidated view of booking performance across different cities, hotels, OTAs, payment statuses and room types.

## Key Metrics

- Total Bookings
- Average Length of Stay
- Total Revenue
- Total Commission Cost
- Gross Amount

## Dashboard Analysis

The dashboard covers:

- OTA Performance
- City-wise Revenue Performance
- Revenue Quality Analysis
- Payment Status Distribution
- Hotel-wise Performance
- Room Type Performance
- Total Bookings by City

## Key Analysis

The dashboard enables users to:

- Compare revenue performance across different cities.
- Analyze contribution from different Online Travel Agencies (OTAs).
- Identify high- and low-performing hotels.
- Evaluate payment-status distribution.
- Compare hotel and room-type performance.
- Analyze commission costs and overall revenue performance.
